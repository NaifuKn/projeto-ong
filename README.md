
# ONG PLACEHOLDER

## Sobre o projeto

Projeto acadêmico de desenvolvimento front-end que simula
o site de uma organização não governamental (ONG).

O objetivo é apresentar iniciativas sociais e disponibilizar
informações sobre os projetos e as formas de contato.

## Tecnologias utilizadas

- HTML5: estrutura e organização das páginas.
- CSS3: estilização, responsividade e apresentação visual.
- JavaScript: interatividade e funcionalidades da interface.
- Git e GitHub: versionamento e organização do projeto.

## Estrutura do projeto

- index.html: página inicial.
- projetos.html: apresentação dos projetos sociais.
- contato.html: página de contato.
- style.css: estilos visuais.
- script.js: funcionalidades JavaScript.

## Como executar

1. Baixe o projeto pelo GitHub utilizando Code > Download ZIP.
2. Extraia o arquivo ZIP no computador.
3. Abra a pasta do projeto.
4. Execute o arquivo index.html em um navegador.

O projeto utiliza HTML, CSS e JavaScript e não precisa
de instalação de dependências externas.

## Funcionalidades

- Navegação entre as páginas.
- Apresentação dos projetos sociais.
- Formulário de contato.
- Estilização responsiva.
- Funcionalidades interativas em JavaScript.

## Versionamento

O projeto utiliza uma estrutura baseada em GitFlow:

- main: versão principal e estável.
- develop: integração das funcionalidades.
- feature: desenvolvimento de novas funcionalidades.
- release: preparação de lançamentos.
- hotfix: correções na versão principal.

As alterações são registradas por commits e integradas
por meio de Pull Requests.

## Testes

O projeto pode ser verificado manualmente no navegador,
conferindo a navegação, o layout responsivo e as
funcionalidades JavaScript.
